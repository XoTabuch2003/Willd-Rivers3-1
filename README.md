# Дикі річки України

Повноцінний живий веб-застосунок — енциклопедія та архів польових спостережень водного світу України.

**Демонстрація:** після публікації на GitHub Pages сайт буде доступний за адресою  
`https://ВАШ_НІК.github.io/НАЗВА_РЕПОЗИТОРІЮ/`

---

## Швидкий старт на GitHub Pages (5 хвилин)

### 1. Створіть репозиторій
1. Зайдіть на [github.com/new](https://github.com/new)
2. Назва репозиторію: наприклад `dyki-richky` або `wild-rivers-ukraine`
3. Зробіть **Public**
4. **Не** ставте галочки на README / .gitignore / license
5. Натисніть **Create repository**

### 2. Завантажте файли
**Варіант А — через сайт GitHub (найпростіше з телефону/ноутбука):**
1. У новому репозиторії натисніть **uploading an existing file**
2. Перетягніть **усі файли** з цієї папки (index.html, app.js, styles.css, articles.json, logo.png, усі картинки тощо)
3. Внизу напишіть commit message: `Перший запуск сайту`
4. Натисніть **Commit changes**

**Варіант Б — через Git (якщо вмієте):**
```bash
git clone https://github.com/ВАШ_НІК/НАЗВА_РЕПО.git
cd НАЗВА_РЕПО
# скопіюйте всі файли з цієї папки сюди
git add .
git commit -m "Перший запуск сайту Дикі річки України"
git push
```

### 3. Увімкніть GitHub Pages
1. У репозиторії перейдіть у **Settings** → **Pages** (зліва)
2. У розділі **Source** виберіть **Deploy from a branch**
3. Branch: `main` (або `master`), папка: `/ (root)`
4. Натисніть **Save**
5. Через 1–2 хвилини з’явиться посилання:  
   `https://ВАШ_НІК.github.io/НАЗВА_РЕПО/`

Готово! Сайт живий і доступний усім.

## Як оновлювати контент (додавати нові спостереження)

### Спосіб 1 — зручний (рекомендований)
1. Відкрийте свій сайт
2. Перейдіть у **«Додати спостереження»**
3. Заповніть форму (фото, геолокація, опис, водний ресурс тощо)
4. Натисніть **Зберегти**
5. Натисніть **Експорт JSON** — завантажиться файл `articles.json`
6. У GitHub репозиторії:
   - Відкрийте файл `articles.json`
   - Натисніть олівець (Edit)
   - Видаліть старий вміст і вставте новий з експортованого файлу
   - **Commit changes**
7. Через 30–60 секунд оновлення з’являться на сайті для всіх

### Спосіб 2 — прямо в GitHub
Редагуйте файл `articles.json` прямо на GitHub (кнопка олівця). Структура зрозуміла — просто копіюйте існуючий об’єкт статті і змінюйте поля.

## Встановлення на телефон (PWA)

Застосунок є **Progressive Web App** — його можна встановити на головний екран телефону і користуватися як звичайною програмою (навіть офлайн).

### Android (Chrome / Edge)
1. Відкрийте сайт у Chrome.
2. Натисніть меню **⋮** → **«Додати на головний екран»** або **«Встановити застосунок»**.
3. Підтвердіть. Іконка з’явиться на робочому столі.

### iPhone / iPad (Safari)
1. Відкрийте сайт у **Safari** (важливо — не в Chrome).
2. Натисніть кнопку **«Поділитися»** (квадрат зі стрілкою вгору).
3. Прокрутіть і виберіть **«На екран «Додому»»**.
4. Натисніть **«Додати»**.

Після встановлення застосунок відкривається на весь екран, без адресного рядка браузера, і працює офлайн (фото, тексти, каталог).
